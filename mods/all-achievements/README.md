# Мод: все достижения

Отдельный мод для русского перевода
**Hunter: The Reckoning — The Beast of Glenkildove**. Добавляет в главное меню
пункт «Открыть все достижения.», который разблокирует все 41 достижение во
внутриигровом списке.

Мод не входит в основной оверлей перевода и устанавливается отдельно.

## Установка

1. Установите основной перевод из корня репозитория (скопируйте `deploy/`
   поверх папки `deploy` игры).
2. Сделайте резервную копию `deploy/ui.js`.
3. Скопируйте `ui.js` из этой папки в `deploy/` игры, заменив файл перевода.
4. Откройте игру. Если браузер кэшировал старые файлы, обновите страницу с
   очисткой кэша (Ctrl+F5).

## Использование

1. Откройте главное меню.
2. Выберите «Открыть все достижения.».
3. Игра покажет экран достижений со всеми открытыми пунктами.

Разблокировка сохраняется в хранилище браузера и остаётся после перезапуска
игры.

## Удаление

Верните на место `deploy/ui.js` из основного релиза или из резервной копии.
Сами достижения при этом останутся открытыми — они хранятся отдельно от
файлов игры. Чтобы сбросить их, очистите данные сайта в браузере.

## Ограничения

- Мод рассчитан на браузерную и Steam-версию с файловой структурой `deploy`
  (проверено на сборке `71160`).
- Открываются достижения во внутриигровом списке. Достижения платформы
  (Steam, Game Center) могут не активироваться.
- Сцены, сохранения и покупки мод не изменяет.
